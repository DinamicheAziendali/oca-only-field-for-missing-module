**Italiano**

Questo modulo permette di inviare fatture xml tramite pec anche se il server mail è archiviato.

Bisogna comunque associare i server pec in entrata e in uscita sul canale sdi(a sua volta impostato sui setting)

**English**

This module allow to send xml invoice with pec also if server mail is archived.

However, it is necessary to associate the incoming and outgoing pec servers on the SDI channel (in turn set in the settings)
